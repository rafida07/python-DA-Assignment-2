# python-DA-Assignment-2 – Data Visualization

Project Overview

This project focuses on data visualization using Python. The Seaborn Taxis dataset is used to explore taxi trip data and understand the relationships between different variables.

Dataset

* Dataset Name: Taxis
* Source: Seaborn built-in dataset

Libraries Used

* Pandas
* Matplotlib
* Seaborn

Tasks Performed

1. Loading the Dataset

Loaded the Taxis dataset using Seaborn.

2. Handling Missing Values

* Checked for missing values in the dataset.
* Handled missing values using suitable strategies.
* Removed rows with missing values where necessary.

3. Visualizations using Matplotlib and Pandas

* Line Chart – Visualized fare over pickup time.
* Bar Chart – Displayed total fare by pickup borough.
* Pie Chart – Showed trip distribution by payment method.
* Histogram – Visualized the distribution of trip distance.
* Box Plot – Compared tip amounts across pickup boroughs.

4. Visualizations using Seaborn

* Count Plot – Showed the number of trips in each pickup borough.
* Scatter Plot – Explored the relationship between distance and fare.
* Heatmap – Visualized correlations between numerical variables.
* Pair Plot – Compared pairwise relationships between numerical variables.
* Violin Plot – Displayed fare distribution by payment method.

Conclusion

This assignment helped me practice data cleaning and data visualization using Python. The charts helped me understand trip distributions, fare patterns, and relationships between numerical variables.
